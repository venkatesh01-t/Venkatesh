The Challenge

Standard atmospheric forecasting relies on compute-heavy numerical weather prediction (NWP) supercomputers that run slowly and struggle with localized micro-climate variations. The goal was to build a nimble, lightweight machine learning model that could process historical barometric pressure, relative humidity, wind velocity, and ambient dew points to output rapid localized forecasts.

Engineering & ML Architecture

Data Cleaning & Feature Scaling

Preprocessed extensive historical weather datasets using Pandas and NumPy, handling missing sensory values and applying StandardScaler normalization.

KNN Hyperparameter Tuning

Tuned K-Nearest Neighbors hyper-parameters via GridSearchCV cross-validation to identify optimal neighborhood cluster metrics (k=7) for precipitation classification.

Live API Sensor Ingestion

Integrated OpenWeatherMap REST endpoints to pull real-time ground truth atmospheric metrics for on-the-fly inference and evaluation.

Interactive Data Visualization

Rendered dynamic temperature curves, pressure variances, and rainfall probabilities through interactive Matplotlib and Chart.js UI dashboards.

Tech Stack

Python 3.11 Scikit-Learn Pandas & NumPy OpenWeatherMap API Matplotlib & Seaborn Flask / REST
